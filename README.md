## Tech Stack

### Frontend

- Next.js 16
- React 19
- TypeScript

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- Socket.io
- JWT
- Swagger

### Other

- Cloudinary
- Nodemailer
- Zod
- pnpm Workspace
